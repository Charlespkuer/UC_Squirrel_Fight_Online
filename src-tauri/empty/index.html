没找到游戏目录

这个 EXE 是联机版的轻壳：它自己不存前端，启动时去仓库目录里读 scripts/index-online.html 与 js/ css/ images/。现在没找到这些文件。

三种处理方式（任选一种）：

① 把 EXE 放回仓库根目录（和 AGENTS.md 同一层）再打开；

② 设环境变量 SSDZ_GAME_DIR 指向仓库根目录再打开；

③ 想给玩家用：改用 src-tauri/dist/squirrel_fight_online.exe（自带前端的完整包）。

排查时可以设 SSDZ_SHELL_LOG=1，找目录的过程会写到 %TEMP%\ssdz-online-shell.log。
