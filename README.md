# 松鼠大战 Online（联机版）客户端

《松鼠大战》（UC 乐园）怀旧复刻的**联机版客户端内容**：服务端权威的网页游戏前端，纯静态、没有构建步骤。

等级、装备、战斗、掉落、天梯、征战、师徒与每日进度全部由服务器计算并落库；客户端只负责显示，
并把操作（动作）发上去 —— 本地的 `State.save()` 是空操作，发奖函数一律抛错。

- 版本：**1.0.56**（客户端内容快照：2026-11-14）
- 线上服务器：`http://140.143.142.110:5896`（`/api/health` 可自检）
- 本仓库**只有客户端**：服务端、桌面壳（Tauri）、出包与测试工具都不在这里

## 在浏览器里跑这份内容

页面必须来自 **http**：服务器只有 `http://…:5896`，`https` 页面发请求会被浏览器的混合内容策略拦掉。

```bash
npx serve .                 # 或：python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

- `index.html` 带 `<base href="/">`，只能部署在**站点根路径**，不要放进子目录。
- 服务器地址在 `online-config.js` 的 `window.__SSDZ_ONLINE_API__`；也可以在浏览器
  `localStorage['ssdz-online-base']` 里改（等同客户端设置页里的服务器地址）。
- 首次进入需注册账号（一设备一账号）；进度存在服务器，换设备登录同一账号即可继续。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html` | 唯一入口，脚本加载链在这里 |
| `online-config.js` | 服务器地址与版本号（构建时写入） |
| `js/` | 全部客户端代码：网络出口 `net.js`、权威镜像 `online.js`、经典界面 `ssfight/` 等 |
| `css/` | 经典界面样式，以及联机新增的少量交互样式 |
| `images/` | 运行时素材；`images/ssfight/ui/` 是原版导出的经典界面元件 |
| `audio/` | 战斗音效与主界面 BGM |
| `shared/actions.json` | 动作白名单（客户端从 `/api/meta` 拿同一份） |
| `scripts/version.json` | 版本标识（更新检查用） |
| `web-manifest.json` | 本快照的文件清单：路径 / 大小 / SHA-256 + 聚合 `build` 指纹 |

## 版本一致性

服务端也加载同一批 `js/` 内核（数值、战斗、结算），所以**客户端与服务端必须是同一版本**；
版本错开时战斗与结算可能对不上。`web-manifest.json` 的 `build` 是整份前端的指纹，
版本号没变但文件有改动时它也会变。

本仓库是发布用快照（由开发仓库 `node tools/build-online-app.cjs --web` 生成后导出），
不在这里改源码。
